# Hotel Booking Service (Spring Framework)

## Описание проекта

Данный проект — это бэкенд-составляющая сервиса бронирования отелей, разработанная в рамках финальной работы курса **«Разработка на Spring Framework»**.

Приложение предоставляет REST API для:
- поиска и управления отелями и комнатами;
- бронирования комнат пользователями;
- управления пользователями и ролями;
- выставления рейтингов отелям;
- фильтрации и пагинации данных;
- сбора и выгрузки статистики работы сервиса в формате CSV.

Проект реализован с использованием Spring Boot и построен по слоистой архитектуре.

---

---

## Архитектура

Приложение разделено на логические слои:

- Controller — REST API
- Service — бизнес-логика
- Repository — доступ к данным
- DTO — объекты передачи данных
- Mapper — маппинг DTO ↔ Entity (MapStruct)
- Statistics layer — сбор и обработка статистики (Kafka + MongoDB)

---

## Основные сущности

- Hotel — отель
- Room — комната в отеле
- User — пользователь (USER / ADMIN)
- Booking — бронирование комнаты
- StatisticEvent — статистические события

---

## Функциональность

### Отели
- CRUD-операции
- Изменение рейтинга (оценки от 1 до 5)
- Поиск с фильтрацией и пагинацией

### Комнаты
- CRUD-операции
- Поиск с фильтрацией и пагинацией
- Фильтрация по доступности дат

### Пользователи
- Регистрация пользователей
- Роли: USER и ADMIN
- Проверка уникальности логина и email

### Бронирование
- Бронирование комнат на свободные даты
- Получение списка бронирований (с пагинацией)

### Статистика
- Сбор событий регистрации пользователя
- Сбор событий бронирования комнаты
- Асинхронная обработка через Kafka
- Хранение статистики в MongoDB (JSON)
- Выгрузка статистики в CSV-файл (доступно только ADMIN)

---

## Безопасность

- Используется **Spring Security + Basic Auth**
- Доступы:
    - Регистрация — без авторизации
    - CRUD отелей и комнат — только ADMIN
    - Просмотр всех бронирований — только ADMIN
    - Остальные операции — USER и ADMIN (с авторизацией)

---

## Статистика и CSV-выгрузка

Endpoint:

GET /api/v1/statistics/export

- Формат: CSV
- Доступ: только для пользователей с ролью ADMIN

## Запуск проекта

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd hotel-booking
```

### 2. Запуск через Docker Compose

```bash
docker-compose up --build
```

Docker Compose поднимает:
- приложение
- PostgreSQL
- MongoDB
- Kafka
- ZooKeeper
